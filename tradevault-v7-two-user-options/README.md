# TradeVault — Owner / Admin / User Access

## Access rules
- **Owner:** ermiyaskibatu905@gmail.com
- **Admin:** ermiyaskibatu12@gmail.com
- **Admin:** ermik905@gmail.com
- Every other email is a regular **User**.
- Owner/Admin accounts are approved automatically.
- Regular Users are **Pending** for up to 24 hours, or can be approved earlier by Owner/Admin.
- Regular Users have two journal choices after approval: **See Ermiyas Trade** or **Journal Your Trade**.
- **See Ermiyas Trade** shows the Owner's shared journal; **Journal Your Trade** stores the regular user's own private trades.
- Approval contact: Instagram **@ermik905**. The app does not automatically read Instagram DMs.
- Owner/Admin can approve or reject pending users.
- The Owner's shared trades are visible to approved regular users.
- Owner/Admin can manage their own journal trades.

## Run on Windows
Double-click `Start-TradeVault.bat`, then open:
`http://localhost:3000`

Or from Command Prompt:
`node server.js`

Requires Node.js 20+.
